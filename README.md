# 🛒 Tienda Online en Django

Esta aplicación permite gestionar una tienda online básica, con funcionalidades diferenciadas para administradores y clientes.

## 👩‍💻 Funcionalidad por tipo de usuario

### Administradores (staff):
- Agregar, editar y eliminar **categorías** de productos.
- Agregar, editar y eliminar **productos**.

### Clientes (usuarios no admin):
- Agregar productos al **carrito**, modificar cantidades o eliminar productos del mismo.
- **Finalizar la compra**, generando un historial.
- Acceder y editar su **perfil**: nombre, correo, dirección, etc.


## 🖼️ Sobre las imágenes

- La **imagen principal** del inicio está en la carpeta `static/`, como indica la consigna.
- Las imágenes de productos se **suben desde un formulario del admin**, por lo que se guardan en la carpeta `media/`.
- Por buenas prácticas, la carpeta `media/` está incluida en el archivo `.gitignore` y **no se sube al repositorio**.
